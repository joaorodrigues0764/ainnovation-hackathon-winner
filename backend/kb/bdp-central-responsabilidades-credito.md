## O que é
A Central de Responsabilidades de Crédito é uma base de dados gerida pelo Banco de Portugal onde os bancos comunicam os créditos concedidos. Serve para avaliar o risco de dar crédito e identificar incumprimentos. Não é uma pontuação (score) nem uma lista negra: é um registo.

## Como consultar o teu mapa
Cada cliente pode pedir gratuitamente o seu mapa de responsabilidades no site do Banco de Portugal, presencialmente ou por correio. Ver o mapa ajuda a saber que créditos e cartões tens, antes de pedir mais crédito.
